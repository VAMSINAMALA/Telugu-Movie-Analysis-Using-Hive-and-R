# 📊 Telugu Movie Data Analysis using Hive and R

## 📌 Project Overview
This project analyzes Telugu movie data using Big Data technologies like Hive and visualization tools like R. It extracts insights such as trends, audience preferences, genre popularity, and factors affecting movie success.

---

## 🎯 Objectives
- Analyze Telugu movie dataset using Hive queries
- Identify trends in movie production
- Understand audience preferences using ratings
- Explore genre distribution
- Visualize insights

---

## 📂 Dataset Information
- Total Records: 1400

### Attributes:
- Movie Name
- Year
- Certificate
- Genre
- Overview
- Runtime
- Rating
- Movie Ratings Count

---

## ⚙️ Technologies Used
- Python (Pandas, NumPy)
- Hive (HDFS)
- R Programming
- Google Colab
- Hortonworks Sandbox

---

## 🧹 Data Preprocessing
- Filled missing values
- Removed duplicates
- Standardized data types
- Cleaned text fields

---

## 🔍 Analysis Performed

### 📅 Year-wise Analysis
- Movies released each year
- Production trends

### ⭐ Rating Analysis
- Top 10 highest-rated movies
- Movies with rating < 5
- Average rating per year

### 🎭 Genre Analysis
- Most common genres
- Genre-wise movie count

### ⏱ Runtime Analysis
- Movies with runtime > 150 minutes
- Runtime distribution

### 🔎 Content Analysis
- Keyword-based search (e.g., "love")
